# Słownik Języka Trudnego / Dictionary of Sophisticated Polish Words

> Interaktywna aplikacja webowa do nauki i poszerzania zasobu słownictwa o rzadkie, wyszukane i trudne pojęcia w języku polskim.  
> *An interactive web application to learn, review, and master sophisticated Polish vocabulary.*

---

## O projekcie (PL)

**Słownik Języka Trudnego** to aplikacja stworzona z myślą o osobach pragnących wzbogacić swój język o precyzyjne i erudycyjne słownictwo. Każde słowo zawiera poprawną wymowę, skróconą i pełną definicję, etymologię, przykłady użycia w zdaniach oraz odnośnik do Słownika Języka Polskiego PWN.

### Główne funkcje:
- **Algorytm powtórek (Spaced Repetition):** Inteligentny system dopasowujący częstotliwość powtórek do stopnia zapamiętania słowa.
- **Quizy i testy:** Interaktywne ćwiczenia pozwalające sprawdzić i utrwalić wiedzę.
- **Kategorie tematyczne:** Wygodne przeglądanie słów (Filozofia, Psychologia, Język i Mowa, Sztuka i Literatura itd.).
- **Dostępność i personalizacja:** Obsługa wysokiego kontrastu, większej czcionki oraz redukcji ruchu.

---

## About the Project (EN)

**Dictionary of Sophisticated Polish Words** is a web application built for users looking to expand their Polish vocabulary with nuanced and erudite terms. Every entry includes phonetic pronunciation, concise and full definitions, etymology, example sentences, and direct references to the PWN Polish Dictionary.

### Key Features:
- **Spaced Repetition System:** Smart scheduling that adjusts review intervals based on user recall.
- **Interactive Quizzes:** Practice mode with distractors to reinforce word retention.
- **Thematic Categories:** Easy browsing through domains like Philosophy, Psychology, Literature, Ethics, and Logic.
- **Accessibility:** Support for high contrast, larger font sizes, and reduced motion settings.

## Technologie / Tech Stack

- **Framework:** [Svelte 5](https://svelte.dev/) (Runes) & [SvelteKit](https://kit.svelte.dev/)
- **Styling:** [TailwindCSS v4](https://tailwindcss.com/)
- **Menedżer pakietów / Package Manager:** [Bun](https://bun.sh/)
- **Baza danych / Database:** Firebase / Firestore
- **Deploy:** Netlify

## Szybkie uruchomienie / Quick Start

Przed uruchomieniem upewnij się, że masz zainstalowany [Bun](https://bun.sh/).

```bash
# 1. Klonowanie i instalacja zależności / Install dependencies
bun install

# 2. Uruchomienie serwera deweloperskiego / Start dev server
bun run dev

# 3. Sprawdzenie typów i budowanie produkcyjne / Check types & build
bun run check
bun run build
```
